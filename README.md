# Prompt Engineering Task

Hands-on experiments with three prompt engineering techniques, using real prompts and unedited model outputs.

## Setup
- Tool: Google AI Studio
- Model: gemini-3.8-flash
- Temperature: default (not adjustable for this model)
- Thinking level: Low
Recommended: set it to the lowest option (Minimal or Low)

## Experiments
1. Zero-shot vs few-shot (sentiment classification)
2. Chain-of-thought (multi-step reasoning)
3. Structured output (JSON extraction)
